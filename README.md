# LePendu
Jeu du pendu (Hangman)
Le principe du jeu est de déviner le nom du fruit d'une liste.
le joueur doit déviner les lettres composants le fruit.
Exécuter le programme python main_pendu pour lancer le jeu dans la console windows.
Entrez un nom de joueur. Si le joueur existe déjà, il est affiché avec son nombre de points, sinon son nombre de points est zero.
Le joueur doit trouver les lettres formants le nom du fruit à chaque fois.
Les lettres trouvées sont affichées à l'écran, dans le cas contraire des asterix (****) sont affichés.
Le joueur a droit à 10 chances, qui sont décrémentées chaque foid que la lettre n'est pas trouvée.
À la fin du jeu le score du joueur est enregistré et il peut continuer à jouer ou quitter le jeu.

---- English Version -----

The aim of the game is to guess the name of a fruit from a list.
The player must guess the letters that make up the fruit.
Run the Python program `main_pendu` to launch the game in the Windows console.
Enter a player name. If the player already exists, their name and score are displayed; otherwise, their score is zero.
The player must find the letters that spell the fruit's name each time.
The letters found are displayed on the screen; otherwise, asterisks (****) are displayed.
The player has 10 attempts, which are decremented each time a letter is not found.
At the end of the game, the player's score is saved, and they can continue playing or quit.
